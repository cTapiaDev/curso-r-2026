# 🚀 Curso R 2026: Ingeniería de Datos y Análisis Funcional

Bienvenido al repositorio oficial del Curso intensivo de R. Este programa de 15 horas está diseñado para transicionar desde los fundamentos del lenguaje hacia la aplicación práctica de ingeniería de datos, optimización de pipelines y desarrollo de reportes automatizados utilizando metodologías modernas.

## 📌 Sobre el Curso

El curso se estructura en 5 sesiones de 3 horas cada una. El enfoque pedagógico prioriza el *live coding* y la resolución de talleres prácticos autónomos en cada módulo, culminando en un pipeline integrador que simula un entorno real de toma de decisiones.

## 📚 Estructura del Programa

| Módulo | Enfoque Principal | Tecnologías Clave | Estado |
|----|----|----|----|
| Módulo I | Programación y Manipulación Avanzada | `tidyverse`, `purrr`, `data.table` | 🟢 Disponible |
| Módulo II | Automatización y Workflows | `purrr`, iteraciones, control de flujo | 🟢 Disponible |
| Módulo III | Visualización Estratégica de Datos | `ggplot2`, customización avanzada | 🟡 En desarrollo|
| Módulo IV | Análisis Funcional y Modelado Básico | `tidymodels`, inferencia estadística | ⚪ Planificado |
| Módulo V | Despliegue y Reportería Dinámica | `RMarkdown`, `Shiny` | ⚪ Planificado |

## 🗂️ Organización del Repositorio

El espacio de trabajo está estandarizado para facilitar el seguimiento de las clases y la entrega de proyectos:

- `r_modulo_1` a `r_modulo_5`: Carpetas dedicadas a cada sesión. Contienen los scripts iniciales, los datos crudos para los talleres y las pautas de resolución.

- `diapositivas/`: Material de apoyo teórico y arquitecturas conceptuales presentadas durante las sesiones.

- `proyecto_final/`: Especificaciones y rúbricas para el desarrollo del pipeline integrador de 7 ejercicios.

## 🛠️ Tecnologías y Requisitos

Para ejecutar los talleres de este repositorio sin problemas de compatibilidad, asegúrate de contar con el siguiente entorno configurado:

- **Lenguaje:** R (versión 4.2.0 o superior).

- **IDE:** RStudio Desktop.

- **Gestor de Versiones:** Git instalado y enlazado a la sesión de RStudio.

- **Liberías Core:** La suite completa de `tidyverse` (incluyendo `dplyr`, `purrr`, `ggplot2`, `tidyr`, `readr`), además de `lubridate`, `data.table` y `microbenchmark`.
